# Travel&K — сайт

Статический сайт (HTML/CSS/JS) + один PHP-файл для заявок. Работает на любом обычном хостинге с PHP 7.4+.

## Запуск
1. Загрузите всё содержимое папки на хостинг в корень сайта (public_html).
2. Домен travelk.shop уже прописан в canonical, sitemap и og-тегах. Если домен поменяется: `python3 set-domain.py https://новый-домен`.
3. Подключите заявки в Telegram (ниже).
4. Отправьте `sitemap.xml` в Яндекс.Вебмастер и Google Search Console.

## Заявки в Telegram (@NikSergF)
Бот не может написать пользователю по @username — нужен числовой chat_id:
1. В Telegram откройте @BotFather → /newbot → получите токен.
2. Откройте созданного бота и нажмите Start (с аккаунта @NikSergF).
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — найдите `"chat":{"id":ЧИСЛО`. Это chat_id.
4. Скопируйте `config.sample.php` в `config.php`, впишите токен и chat_id.
Пока config.php не создан, форма откроет Telegram @NikSergF с готовым текстом заявки (резервный вариант).

## Что редактировать
- Цены и описания — в карточках страниц `ekskursii/<название>/index.html` (или попросите пересобрать сайт из прайса).
- Промокоды партнёров — страница `partnery/index.html` (блоки «Промокод появится здесь»).
- QR-код на странице «Контакты» строится из адреса сайта автоматически и скачивается как SVG.

## Фото
Все фото в формате webp (ужаты до ~20–80 КБ). Часть программ использует тематические фото: при наличии своих замените файлы в `img/`.
