Хуа Хин: королевский курорт рядом с Бангкоком

Хуа Хин — старейший королевский курорт Таиланда. Спокойные пляжи, ночные рынки и прогулки по паркам делают его хорошим выбором для расслабленного отдыха.

Главные места

Дворец Марукхатхаяван с длинными деревянными верандами на берегу, ночной рынок, парки и пляж Хуа Хина. Рядом — национальный парк Сам Рой Йот с болотами и птицами.

Когда ехать

Лучше с ноября по апрель. Хуа Хин считается более «сухим» курортом, чем юг.

Маршруты

В каталоге есть двухдневный королевский тур по Хуа Хину и парку «300 вершин» — подходит для спокойного уикенда.
